Seção 1: Sobre os dados
Estas informações vêm de um conjunto público de dados de e-commerce brasileiro (Olist), com pedidos entregues entre 15/09/2016 e 29/08/2018. São dados de exemplo, para fins de estudo.
Seção 2: Resumo geral
O prazo médio geral de entrega é de 12.1 dias e o prazo mediano é de 10.0 dias. Cerca de 8.1% dos pedidos chegam depois da data estimada. Foram analisados 96470 pedidos entregues, feitos entre 15/09/2016 e 29/08/2018.

Seção 4: Perguntas frequentes 
Pergunta: Como é definido um pedido atrasado?
Resposta: Um pedido é considerado atrasado quando o cliente o recebe depois da data estimada de entrega.
Pergunta: Qual o estado com maior prazo de entrega?
Resposta: Roraima (RR), o prazo médio de entrega é de 29.0 dias.
Pergunta: Quantos pedidos chegam atrasados?
Resposta: Cerca de 8.1% dos pedidos chegam depois da data estimada
Pergunta: Como é calculado o prazo de entrega?
Resposta: É o número de dias entre a data da compra e a data em que o cliente recebeu o pedido.
Seção 5: Limites do assistente
Este assistente não tem acesso a pedidos individuais nem a dados pessoais de clientes. Para consultas sobre um pedido específico, encaminhe para um analista.
